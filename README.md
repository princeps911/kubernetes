# 🎡 Exciting Kubernetes Projects
A collection of hands-on Kubernetes projects demonstrating the journey from basic pod deployments to advanced microservices orchestration.

## 🚀 Project Roadmap

| Project | Focus Area | Key Kubernetes Concepts |
| :--- | :--- | :--- |
| [01-Basic-Deployment](./01-basic-deployment) | Fundamentals | Pods, Services, Env Variables, Selectors |
| [02-Stateful-App](./02-stateful-app) | Persistence | StatefulSets, PVC, PV, StorageClasses |
| [03-Voting-App-Microservices](./03-voting-app-microservices) | Orchestration | Kustomize, HPA, Probes, Ingress, NetworkPolicy |

## 🛠️ Global Prerequisites
- **Minikube** (Local Cluster)
- **kubectl** (CLI)
- **Metrics-Server** (Required for Project 03)
