# 01 - Basic CRUD Deployment
This project focuses on the fundamental "atom" of Kubernetes: the Pod and its connection to a database.

### 🎯 Objectives
- Deploy a backend application using `Deployment` objects.
- Connect the application to a PostgreSQL database using environment variables.
- Use `ClusterIP` services for internal communication.

### 🛠️ Key Takeaways
- Learned how **Labels and Selectors** act as the glue between services and pods.
- Managed sensitive data (passwords) using basic environment injection.
